# OcryEdit

作者：**kclg-YSJ** 原作者：**cmdysj**。本项目是在原 **Re:PhiEdit Next** 项目基础上，使用 **AI（DeepSeek）** 进行的重构，是 Ocrythm 的官方制谱器。

当前版本：**0.0.1**。

基于 Canvas、Web Audio、WebGL 和 IndexedDB，支持音符与事件编辑、实时预览、着色器、多谱面管理、热键及设置迁移。当前仍在持续完善
